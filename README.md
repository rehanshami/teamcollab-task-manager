# TeamCollab – Real-Time Task Manager

TeamCollab is a full-stack task management app for agile teams. It allows users to create projects, assign tasks, and collaborate in real-time with updates and notifications.

## Features (MVP)

- JWT-based authentication (login/register)
- Role-based access (Admin, Member)
- Task CRUD (Create, Read, Update, Delete)
- Assign tasks to users
- Real-time updates with SignalR
- Dashboard with task stats

## Tech Stack

- **Frontend:** Next.js, TypeScript, TailwindCSS
- **Backend:** ASP.NET Core Web API, SignalR
- **Database:** SQL Server + Entity Framework Core
- **Auth:** JWT (access & refresh tokens)
- **DevOps:** Docker, GitHub Actions
